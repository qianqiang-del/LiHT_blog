# 前台首页接口设计

> 基础前缀：`/api/v1`
> 统一响应：`{ "code": 0, "message": "成功", "data": ... }`

---

## 1. 文章流列表

`GET /api/v1/articles`

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `page` | int | 是 | 页码，从 1 开始 |
| `size` | int | 是 | 每页条数，≤100 |

**响应**

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "list": [
      {
        "id": 12,
        "title": "Vue 3 组合式 API 入门",
        "summary": "这篇文章主要介绍...",
        "cover": "https://...",
        "category": { "id": 2, "name": "前端" },
        "tags": [ { "id": 3, "name": "Vue" } ],
        "author": { "id": 1, "nickname": "牵强", "avatar": "https://..." },
        "view_count": 1284,
        "like_count": 36,
        "comment_count": 12,
        "hot": 5,
        "published_at": "2026-08-10T09:30:00Z"
      }
    ],
    "total": 24,
    "page": 1,
    "size": 10,
    "total_page": 3
  }
}
```

## 2. 作者信息

`GET /api/v1/author`

**无参数**

**响应**

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "id": 1,
    "nickname": "牵强",
    "avatar": "https://...",
    "bio": "全栈开发者，记录技术与生活",
    "github": "https://github.com/xxx",
    "stats": {
      "articles": 24,
      "categories": 5,
      "tags": 12
    }
  }
}
```

## 3. 热门排行

`GET /api/v1/hot`

**无参数**，固定返回 6 条，按 `hot` 降序。

**响应**

```json
{
  "code": 0,
  "message": "成功",
  "data": [
    {
      "id": 12,
      "title": "Vue 3 组合式 API 入门",
      "summary": "这篇文章主要介绍...",
      "cover": "https://...",
      "category": { "id": 2, "name": "前端" },
      "tags": [ { "id": 3, "name": "Vue" } ],
      "author": { "id": 1, "nickname": "牵强", "avatar": "https://..." },
      "view_count": 1284,
      "like_count": 36,
      "comment_count": 12,
      "hot": 5,
      "published_at": "2026-08-10T09:30:00Z"
    }
  ]
}
```
