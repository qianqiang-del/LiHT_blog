深入理解 Vue 3 组合式 API：从 Options 到 Composition 的优雅蜕变

前端 2026-07-12 1,284 次浏览 36 赞 12 条评论

Vue 3 的 Composition API 是近年来前端框架中最重要的革新之一。它不仅改变了我们编写 Vue 组件的方式，更深刻地影响了前端代码的组织哲学。

为什么需要 Composition API？

在 Vue 2 中，同一个功能的代码会被分散在 data、computed、methods、watch 等选项中。Composition API 允许我们将相关逻辑聚合在一起。

Composition API 的核心目标不是替代 Options API，而是提供更灵活的逻辑组织和复用方式。

基础用法示例

import { ref, computed } from 'vue'

function useCounter(initial = 0) {
  const count = ref(initial)
  const double = computed(() => count.value * 2)
  function increment() { count.value++ }
  function decrement() { count.value-- }
  return { count, double, increment, decrement }
}

通过将计数器逻辑封装在 useCounter 中，我们可以在多个组件中复用这段逻辑。
